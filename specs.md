# Technical specifications

- Runtime: Cloudflare Worker `patchs-world`, entry [worker/index.mjs](worker/index.mjs), config [worker/wrangler.toml](worker/wrangler.toml).
- Routes: none of its own. The company website forwards `containedevolution.com/patch*` to it through a service binding.
- Service bindings: `AUTH_SERVICE` → `ce-auth-candidate`. [accounts.mjs](worker/accounts.mjs) reads the Contained Evolution session cookie and checks it there.
- Storage: one SQLite-backed Durable Object, `PatchWorld`, keyed `patch`. It holds Patch's body under `body`.
- Body: [worker/body.mjs](worker/body.mjs). It steps from activity to activity when state is read, so it needs no timer. His day follows New York time.
- Mind: [worker/mind.mjs](worker/mind.mjs), [persona](worker/persona.mjs). A Durable Object alarm wakes it every 30–60 minutes while he's awake, and the evening wake also writes his diary. It calls OpenRouter (`OPENROUTER_API_KEY` secret) with a main and a backup model per tier, only on hosts that don't keep prompts, and stops at $24 a month.
- Memory: his life story in [worker/persona.mjs](worker/persona.mjs) is the centre; childhood memories in [worker/seed/childhood.json](worker/seed/childhood.json) each carry a feeling, a strength and tags. [worker/memory-graph.mjs](worker/memory-graph.mjs) links memories through shared tags and lights them from what he is doing, feeling, noticing or reading; the brightest go into his thinking. Island memories, recall times, the last lit set, categories, thoughts, words and diary entries live in the Durable Object. Shape: [shared/memory.js](shared/memory.js).
- API: `GET /patch/api/state` returns the shape in [shared/state.js](shared/state.js), including activity end and speech expiry times. `GET /patch/api/journal` returns recent thoughts, diary entries, learned words and spend. `GET /patch/api/memory` returns categories, all memories, the tag graph and what last lit up.
- Letters and message board: [letters.mjs](worker/letters.mjs) holds the limits. `GET /patch/api/me`; `GET`/`POST /patch/api/letters` and `POST /patch/api/board` need an account; `GET /patch/api/board?before=` is public; `POST /patch/api/board/<id>/report` and `/block`. Posts and letters pass the automatic filter in [mind.mjs](worker/mind.mjs) first. POSTs must come from `https://containedevolution.com`.
- Viewer: [world/src/terrain.js](world/src/terrain.js) defines the shared island heights, coast and places; the island has no trails. [world/src/patch-motion.js](world/src/patch-motion.js) steers Patch around trees and plans his roaming from the activity start time, so every visitor sees the same choices. [world/src/island.js](world/src/island.js) renders the island, water and landmark scenery; [world/src/forest.js](world/src/forest.js) shares tree placement with visitor collision. [world/src/traversal.js](world/src/traversal.js) plans Patch's branch and rope transfers around tree trunks. [world/src/visitor-controls.js](world/src/visitor-controls.js) controls independent walking and flight. [world/src/community.js](world/src/community.js) connects the letters and board panels to the visitor API; [community.html](world/community.html) presents them independently of the island. [memory.html](world/memory.html) and [memory-galaxy.js](world/src/memory-galaxy.js) render the memory API with three.js, shared-tag connections and 30-second live recall polling.
- Static assets: `world/dist`, served under `/patch/`. [prepare.mjs](worker/scripts/prepare.mjs) builds the world if present and adds the Pangolin font (OFL).
- Tests: `npm test` in `worker/`. Deploy: `npm run deploy` in `worker/`. If a new Durable Object method answers "RPC receiver does not implement the method" after a deploy, deploy again.
