# Patch's World

Patch is a five-year-old monkey living alone on a jungle island, and he is Contained Evolution's living AI. Anyone can watch him at `tenari.world/patch`. Contained Evolution account holders can write to him.

- `world/`: the island and Patch, drawn in the browser with Three.js.
- `worker/`: the Cloudflare Worker that runs his body, mind, memory and letters.
- `shared/`: the state the two sides agree on: [state.js](shared/state.js).
